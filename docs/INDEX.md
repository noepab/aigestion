## 🔄 Mantenimiento

Este índice se genera automáticamente mediante el script \scripts/generate-docs-index.ps1\.
Para regenerarlo manualmente:

\\\powershell
.\scripts\generate-docs-index.ps1
\\\

Para organizar archivos .md dispersos:

\\\powershell
.\scripts\organize-docs.ps1
\\\

## 📝 Contribuir

Al crear nuevos documentos:
1. Colócalos en la carpeta \docs/\ apropiada
2. Ejecuta \organize-docs.ps1\ si están fuera de \docs/\
3. El índice se actualizará automáticamente
